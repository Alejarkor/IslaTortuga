Coloca aquí "login-bg.jpg" para usar tu fondo fotográfico en la pantalla de login.

- Nombre exacto: login-bg.jpg  (se sirve en la raíz como /login-bg.jpg)
- Recomendado: 1920x1080 o superior, horizontal, escena nocturna.
- Si no existe el archivo, el login muestra un fondo atmosférico CSS de respaldo
  (no se rompe nada).

Para cambiar el nombre/ruta, edita la regla url("/login-bg.jpg") en
src/styles/login.css.
